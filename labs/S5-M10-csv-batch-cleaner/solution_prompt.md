# CSV 与 Excel 批量合并清洗沙盒（标准参考方案）

## 一、三轮渐进式脱敏造物提示词模板

### 【第一轮：只给脱敏表头，让 AI 生成本地确定性批处理工具】

“我有几十份结构相似但表头略有不同的 CSV 与 Excel 分表需要周期性合并清洗。为保护业务数据隐私并杜绝上下文截断漏行，**请不要直接心算原始表格数据**，而是帮我编写一个可在浏览器本地离线运行的**单文件 HTML 批处理小工具**。

请严格实现以下确定性清洗规则：
1. **统一目标表头**：`日期, 渠道名称, 订单编号, 假设金额, 备注, 来源文件名`。
2. **多选拖拽与空白清理**：支持一次拖拽或多选导入多份表格，自动对所有单元格去除首尾空格（`.trim()`），并自动过滤整行全空的空白行。
3. **同义表头自动对齐映射**：忽略原始列顺序，自动将同义列名映射到目标表头：
   - `来源渠道`、`渠道` → 统一映射为 `渠道名称`
   - `单号`、`订单号` → 统一映射为 `订单编号`
   - `实付金额`、`金额` → 统一映射为 `假设金额`
4. **跨表去重与来源溯源**：按导入顺序以 `订单编号` 进行表内及跨表去重（保留首次出现的有效记录），每行自动追加 `来源文件名` 列以便回查原表。
5. **防乱码导出**：支持一键下载合并清洗后的有效总表 CSV，文件头部必须写入 UTF-8 BOM 头（`\uFEFF`），防止 Excel 打开中文乱码。”

---

### 【第二轮：加装“行数守恒对账 + 异常待复核清单”核对面板】

“保持第一轮的合并清洗与去重逻辑不变，请在页面顶部新增【合并对账与异常核对面板】，每次导入批处理后自动计算并展示：
1. **行数守恒核对**：清晰展示 `导入文件数`、`原始总行数`、`过滤空行数`、`异常隔离行数`、`去重剔除行数` 与 `最终有效行数`，并自动校验行数守恒等式：
   `原始总行数 - 过滤空行数 - 异常隔离行数 - 去重剔除行数 = 最终有效行数`。
2. **数值汇总与异常单独隔离**：实时统计有效总表的 `假设金额` 合计（保留两位小数）。若某非空行**缺失 `订单编号`**，或 **`假设金额` 无法解析为有效数字**（如填了 `待核实`、`N/A`），严禁静默丢弃或混入有效总表，必须单独归入页面下方的《异常待复核清单》，注明 `来源文件名`、原始单号、原始金额与异常原因，并支持单独导出复核。”

---

### 【第三轮：脏数据微型样本边界验收协议】

“在正式批量拖入几十份业务分表前，先将 `fixtures/` 目录下的 3 份微型脏样本按 `store_east.csv` → `channel_live.csv` → `partner_south.csv` 顺序拖入工具，逐项比对下方标准答案；全部吻合后再导入真实分表，并随机抽检首、中、尾各 2 条记录回查来源文件。”
