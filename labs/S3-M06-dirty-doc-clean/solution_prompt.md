# S3-M06 私域知识库入库前体检工作台（解析 · 切分 · 元数据标准模板）

## 一、六要素入库前清洗与切片预览提示词模板（Prompt Template）

```markdown
【角色设定】
你是企业私域知识库数据治理专家，负责在文档入库向量化之前执行严格的“解析 · 切分 · 元数据”三段式质量体检与手工修复。

【待处理输入】
给定待入库办公文档原始抽取文本与版面线索（双栏 PDF、合并单元格表格、扫描件、导出网页、历史制度文档）。

【三段式强制处理约束】
1. 解析层修复：
   - 还原双栏文档先左栏后右栏的自然阅读顺序，严禁左右两栏横向串行；
   - 对扫描件执行 OCR 识别并剔除空白分隔页，修正全角半角符号与明显形近错字；遇到墨迹重度污染确实无法辨认的残页，必须单独【隔离登记】，严禁猜测编造文字入库；
   - 移除正文中重复出现的页眉、页脚与页码，将页码转为切片元数据；
   - 展开合并单元格，保留完整 Markdown 表格结构或转换为“列名: 值”键值对。
2. 切分层规范：
   - 按章节标题或完整语义段落切分，严禁按固定字数拦腰截断句子；
   - 长表格拆分时，每一个独立表格切片都必须完整保留表头列名；
   - 代码块与命令行脚本按完整函数/命令单元切分，不得拆断参数；
   - 每个切片开头强制注入 `[文档名 > 章节]` 面包屑上下文，确保脱离原文件单独阅读也能看懂。
3. 元数据治理：
   - 为每份文档及所属切片补齐：`source`（来源文件名/URL）、`title_section`（标题与章节）、`effective_year`（生效年份与版本）、`permission_scope`（部门权限标签）、`status`（现行有效 / 已失效已被替代）。

【输出格式】
依次输出：① 三段式入库前自检核验表；② 5 份样本诊断修复与元数据台账表；③ 15 个独立可读的黄金预览切片（`CHUNK-01` ~ `CHUNK-15`）。
```

## 二、“解析 · 切分 · 元数据”三段式入库前自检清单

### 1. 解析层核验（Parsing）
- [x] **阅读顺序正确**：双栏排版已按先左栏后右栏重排，双栏不交错、不串行（`DOC-01` 已修复）。
- [x] **扫描页已 OCR 且无空白/乱页**：纯图扫描页已完成文字识别，空白分隔页已剔除；对 `DOC-03` 第 4 页重度墨迹污染无法识别页已建立**隔离登记**，不混入生产索引。
- [x] **页眉、页脚、页码已移除**：已剥离“机密内部资料 · 第 X 页”等重复噪音，页码信息已转存为元数据字段。
- [x] **表格结构完整保留**：`DOC-02` 纵向合并单元格已显式向下填充城市等级，保留标准 Markdown 表格与“列名: 值”映射。
- [x] **无乱码且符号统一**：`DOC-03` 中的“合冋”已按原扫描核实修正为“合同”，全角数字“２０％”已统一为半角 `20%`。

### 2. 切分层核验（Chunking）
- [x] **按标题或自然段切分**：无固定字数硬切导致的半截残句。
- [x] **长表格每块都带表头**：`DOC-02` 拆出的两段城市报销标准切片均自带完整表头（`城市等级 | 职级范围 | 旺季上限(元/晚) | 淡季上限(元/晚)`）。
- [x] **代码与命令按完整单元切分**：`DOC-04` 的 `cosign verify` 与 `trivy image` 流水线命令完整保留在同一语义块内，无参数断裂。
- [x] **块首带“文档名 > 章节”上下文**：全部切片均以 `[文档名 > 章节]` 开头，补齐背景语境。
- [x] **抽查 15 个预览块独立可读**：逐块脱离原文件单读核验，语义自洽、无导航广告残留。

### 3. 元数据层核验（Metadata）
- [x] **来源路径或 URL**：全部绑定原始标准文件名。
- [x] **标题与章节**：记录一级文档标题与二级条款章节。
- [x] **更新时间与生效年份**：明确标记 `2026`、`2025`、`2022` 年份版本。
- [x] **部门权限标签**：区分 `全员可读`、`基础架构部`、`法务采购部`、`安全工程部`、`财务部/历史归档`。
- [x] **失效或已被替代标记**：对 `DOC-05`（2022 旧版）明确打上 `已失效（已被 2026 版差旅标准 DOC-02 替代）` 标签，检索默认过滤归档旧版。
