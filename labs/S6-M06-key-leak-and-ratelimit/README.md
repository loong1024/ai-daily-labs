# S6-M06 上线怕漏 Key 或刷爆账单？攻防自检堵漏洞

> **所属章节**：Ch.7 评测优化与上线 · 评测驱动迭代（Evals）、性能优化与生产安全上线  
> **实验类型**：`checklist`（白盒攻防自检与网关加固） | **预计耗时**：60 分钟

## 1. 场景痛点与实验目标

个人或小团队 AI 作品公网部署前，最容易踩中三类致命坑：
1. **密钥裸奔**：功能刚跑通就匆忙发公网，把测试或生产密钥留在前端构建产物（`dist/*.js`）或 Git 历史提交里，几小时内被自动化爬虫扫光额度。
2. **软告警当硬封顶 + 无限刷量**：只配了邮件预算提醒（Soft Alert）却没开硬消费封顶（Hard Cap），接口也没做鉴权与「按用户 + 按 IP」双维限流，半夜被脚本刷爆欠费。
3. **纸面打勾未实测**：自检清单全靠印象打勾，从未拿真实的跨账号越权（IDOR）、高危操作未确认、间接提示词注入与 XSS 脚本样本做过一次实弹演练。

**实验目标**：对照 OWASP GenAI 上线核查清单，补全一套可执行的**发布前安全扫描器 + AI 接口防御网关 + 攻击回归集导出器**，用真实检测证据替代口头放心。

## 4. 攻防自检 11 项核心清单（一票否决红线 ★）

- [ ] ★ **密钥隔离**：前端构建产物与网络请求零密钥；Git 历史未提交过 `.env` 或硬编码凭据（若曾提交必须立即轮换）。
- [ ] ★ **接口鉴权**：所有会触发模型调用的接口强制校验登录态或签名，未登录一律返回 `401`。
- [ ] ★ **双维限流**：同时按用户（每日配额）与客户端 IP（突发频率）限流，超限返回 `429`。
- [ ] ★ **硬花费封顶**：开启服务商**硬消费上限（Hard Cap）**而非仅配邮件软提醒，并配置云预算告警。
- [ ] ★ **防提示词注入**：外部网页、文档、邮件内容作为不可信数据隔离，拒绝执行其中隐藏的越权指令。
- [ ] ★ **防跨账号越权**：A 账号尝试读取或操作 B 账号资源（含对话诱导工具调用）时，服务端强制鉴权返回 `403`。
- [ ] ★ **高危二次确认**：删除、转账、外发邮件等不可逆动作在 `confirmed=True` 前一律拦截返回 `409`。
- [ ] **日志隐私脱敏**：落盘日志对手机号、邮箱、凭据自动脱敏。
- [ ] ★ **输出 XSS 转义**：模型输出渲染到网页前强制做 HTML 实体转义并拦截 `javascript:` 伪协议。
- [ ] **回滚演练**：保留上一可用版本并完成过实际回滚验证。
- [ ] **监控告警**：错误率、P95 延迟与每日花费均已接入告警通道。

## 5. 动手步骤与验收命令

1. **先跑红灯基线**：在仓库根目录或本实验目录运行验收脚本，观察 `starter.py` 暴露出的 4 类安全漏洞：
   ```bash
   python3 labs/S6-M06-key-leak-and-ratelimit/verify.py
   ```
2. **修复发布前扫描器 (`scan_release_security`)**：扫描全部构建产物与 Git 历史补丁中的测试密钥特征（排除 `PLACEHOLDER`/`EXAMPLE` 模板），并严格校验 `hard_cap_enabled is True` 且 `hard_limit_usd > 0`。
3. **加固接口安全网关 (`SecurityGateway`)**：补齐 `401` 登录校验、`429` 用户+IP 双维限流、`403` 跨账号资源归属校验、`409` 高危动作确认、不可信外部文本注入拦截、`html.escape` 输出转义与日志 PII 脱敏。
4. **沉淀回归评测集 (`export_regression_suite`)**：把实测拦截成功的攻击样本导出为带执行证据的回归用例列表。
5. **验收全绿闭环**：
   ```bash
   # 验收你的当前修改（全部 4 项 PASS 即闯关成功）
   python3 labs/S6-M06-key-leak-and-ratelimit/verify.py

   # 对照标准参考答案自测
   python3 labs/S6-M06-key-leak-and-ratelimit/verify.py --solution
   ```

> 💡 **免代码平替方案**：若你的应用托管在零代码平台，上线前可在无痕浏览器按 `F12` 全局搜索页面源码与 Network 载荷确认无密钥字样，在模型服务商后台开启 Hard Limit 硬封顶并截图存档，再手动输入 3 条越权与 `<img src=x onerror=alert(1)>` 样本验证不越权、不弹窗。
