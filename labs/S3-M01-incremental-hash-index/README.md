- **核心能力积木**：`B07 版面保表头清洗 + 语境抬头切分` · `B08 BM25+向量混合精排 + 权限版本硬过滤` · `B10 幂等防重账本 + 退避死信 + 人工审批门`
- **推荐实现链路**：扫描本地现存笔记目录 → 比对 docs 表历史文件差集级联清空已删文档切片 → 计算文件 SHA-256 指纹跳过未改动笔记 → 事务内先按 doc_id 删光旧块再编码写入新块
- **头号避坑红线**：直接按块序号做 Upsert 覆盖而不先按 doc_id 清空旧切片：一旦笔记改短或删文件，多出来的尾部孤儿旧块就会永久残留在库里误导回答。

## 1. 场景痛点
用本地 SQLite 索引几百篇 Markdown 笔记时，新手常直接 `INSERT` 新切片却忘了按 `doc_id` 清理旧切片，导致改完笔记后“作废旧金额/旧命令”依然残留在检索前 5 名误导回答；或者每次改动 1 篇就重算全部 500 篇的向量！
