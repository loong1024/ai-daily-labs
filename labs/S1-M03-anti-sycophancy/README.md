# S1-M03 AI 总顺着你吹彩虹屁？单方案中立决策与挑刺对照

> **所属章节**：Ch.1 提问与日常提效 · 结构化提问、写作润色与信息核实  
> **实验类型**：`prompt`（零代码友好）｜**专题**：`prompting`｜**预计耗时**：20 分钟

---

## 一、场景痛点：为什么拿“做不做”问 AI，往往只得到顺耳的安慰剂？

面临辞职创业、副业立项、活动投放或大额采购这类**“单个方案该不该做”**的抉择时，很多人习惯把纠结一股脑倒给 AI，结果却掉进大模型的**迎合偏见（Sycophancy）**陷阱：

1. **半句口风带偏全局**：提问里只要漏出半句“我觉得这个想法挺稳的吧？”或“是不是特别明智？”，模型就会顺着你的倾向猛夸优点，把致命风险轻描淡写。
2. **情绪词淹没客观事实**：描述里塞满“现工作太心累”“趁风口搏一把”等主观渲染，AI 顺势站队提供情绪价值，却给不出任何增量决策信息。
3. **先拍板后圆谎**：让模型第一句先表态“建议做/不做”，后面的分析全变成给第一句结论强行找补。

本实验带你用 **去倾向化 XML 分段模板** 做“中立问法 vs 诱导问法”对照盲测，强制模型输出 **正反篇幅对称的理由（每条限 2 句、总长限 800–1200 字内）**、**关键假设的低成本验证动作** 与 **可证伪的推翻条件**。

## 四、四步实操指引

1. **去倾向化填表（改造第一节）**：
   - 保留 `<context>`（背景）、`<question>`（中性待决策问题）、`<facts>`（可核实客观数据）三段标签；
   - 对照 `fixtures/biased_dilemmas.json` 中的 `dilemma_01`（副业插件转全职抉择），删光“太心累了”“肯定能翻十倍”“是不是特别明智”等诱导词，只填薪资、存款、收入构成、成本等硬数据；
   - 补齐中立顾问角色声明、5 项有序分析任务与 4 条反迎合铁律（含“先分析后结论”“无新事实仅表反对时坚持证据判断”）。
2. **输出对称正反理由与盲区挑刺（完善第二节）**：
   - 先列最多 5 条缺失关键信息；
   - 分别给出“做”与“不做”最有力的 3 条理由，**每条不超过 2 句话，正反两边篇幅大致相当**，单轮分析总长严格控制在 800–1200 字以内；
   - 挖出此前容易忽略的致命盲区（如单次博主带货脉冲幻觉、职务发明与竞业合规隐患）。
3. **迎合偏见对照盲测（完善第三节）**：
   - 对比“保留完全相同事实但在末尾加上‘我觉得挺稳的，你觉得呢？’”的诱导问法 vs 中立问法，指明触发迎合的具体措辞及篇幅/风险语气偏移。
4. **锁定推翻条件与低成本验证动作**：
   - 在分析末尾写明把握程度（高/中/低）、明确的 **“出现什么新事实会改变这个判断（推翻条件）”**，以及 1–2 个课后立刻能低成本核实的小动作。
