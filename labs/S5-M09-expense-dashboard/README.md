# [S5-M09] 零代码造网页：15分钟生成个人习惯与开支交互看板

> **所属章节**：Ch.2 Vibe Coding 造物 · Vibe Coding 自然语言造物与 AI 协同开发  
> **实验类型**：`prompt`（单文件交互网页造物包） | **零代码友好**：是 | **预计耗时**：15 分钟

## 1. 场景需求与常见痛点

想拥有贴合个人节奏的习惯打卡与日常开支记录小工具，但市面现成软件广告繁多、字段死板，自己又不想折腾前端框架与开发环境。在用大模型“一句话造网页”时，最容易踩中三个坑：

1. **首轮堆砌过多需求**：一上来抛出十几项功能，生成的代码顾此失彼、按钮点击毫无反应。
2. **刷新即丢数据**：关闭或刷新浏览器后打卡与开支记录瞬间清零，且不知道如何导出备份。
3. **改样式把逻辑改坏**：调整配色布局时让 AI 整段重写，视觉好看了，原本正常的筛选和汇总却算错了。

## 2. 本目录实验资源说明

| 文件路径 | 说明 |
| :--- | :--- |
| `starter.html` | **起点半成品**：具备基础 HTML 表单骨架，但缺少 `localStorage` 持久化、双栏双色响应式样式、筛选统计联动、空值/删除防呆及防乱码 CSV 导出。 |

## 4. 三轮渐进造物步骤指引

### 第一步：首轮最小可用版（MVP）闭环
先打通“录入 → 筛选统计 → `localStorage` 持久化”，不追求花哨动效：
- **录入区**：包含日期（`<input type="date">`）、事项名称、记录类型（`习惯打卡` / `日常开支`）、分类标签（`阅读`、`运动`、`餐饮`、`交通`）和数值（打卡分钟数或假设开支金额）。
- **筛选与汇总区**：顶部支持按记录类型（含 `全部`）与分类标签（含 `全部`）组合筛选，实时计算当前筛选结果下的**累计打卡次数**与**假设开支总额（保留两位小数）**，支持单条删除。
- **本地持久化**：读写 `localStorage`（`getItem` / `setItem`），刷新页面数据不丢失，且**零外部 CDN 链接**。

### 第二步：视觉与防呆交互单点微调
明确约束 AI“保持现有录入、筛选与 `localStorage` 逻辑不变”，仅微调两处：
- **响应式双栏与双色标签**：桌面端采用左录入、右列表圆角卡片布局，移动端（`@media`）自动切换单栏；`习惯打卡` 显示柔和青绿色标签，`日常开支` 显示暖橙色标签。
- **交互防呆**：事项名称去除首尾空格后为空（`.trim()`）时禁止提交并给出轻提示；点击单条“删除”前弹出 `confirm(...)` 二次确认。

### 第三步：示例自检与防乱码 CSV 导出
继续保持既有逻辑不变，新增两个实用按钮：
- **填入示例数据**：一键写入至少 5 条涵盖习惯打卡与假设日常开支的演示记录，方便立即核验筛选与金额汇总。
- **导出 CSV**：将当前筛选列表导出为以 UTF-8 BOM 头（`\uFEFF`）开头的 `.csv` 文件，并对包含逗号或双引号的文本字段做标准双引号转义，确保用 Excel/WPS 打开中文不乱码、不串列。
