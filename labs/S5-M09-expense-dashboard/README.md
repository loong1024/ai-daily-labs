## 1. 场景需求与常见痛点

社区咖啡小店店长、副业工作室主理人或自由创客每天都有几笔经营收支流水，既想实时盯住**总收入、总支出、净结余**和**月度营收目标达成进度条**，又想看清各经营分类占比。但现成记账软件要么广告繁多、要么字段死板，而在用大模型“一句话造网页”时最容易踩三个坑：

1. **首轮贪多导致页面白屏**：一上来塞进多账号登录、云数据库与十几张复杂图表，代码半途截断或按钮点不动。
2. **刷新网页流水瞬间清零**：只存在内存变量里没接本地持久化，关掉浏览器辛苦录入的账目全丢。
3. **改配色把算账逻辑改崩，导出表格中文乱码**：微调样式时不锁边界，把净结余算错；导出 CSV 漏加 UTF-8 BOM 头与双引号转义，Excel 打开乱码串列。

## 4. 三轮渐进造物步骤指引

### 第一步：首轮最小可用版（MVP）——跑通收支净结余、目标进度条与本地存储
先打通“录入 → 筛选算净结余 → 月度目标进度条 → `localStorage` 持久化”，零外部 CDN 依赖：
- **录入区**：包含日期（`<input type="date">`）、事项摘要、收支类型（`经营收入` / `经营支出`）、经营分类（`门店零售`、`线上团购`、`原料采购`、`水电杂费`）与假设金额（元）。
- **月度目标追踪与分类可视化**：支持设定月度营收目标（默认假设 `5000` 元），实时计算达成百分比并渲染可视化进度条（`progress` 宽度随总收入动态伸缩）及分类金额分布条。
- **筛选与四大核心指标**：支持按收支类型（含 `全部`）与经营分类（含 `全部`）组合筛选，实时展示当前筛选下的**流水笔数、经营总收入、经营总支出、净结余（收入 - 支出，均保留两位小数）**，并用 `localStorage` 自动保存流水与目标值。

### 第二步：视觉与防呆交互单点微调
明确约束 AI“保持现有录入、目标计算、筛选与 `localStorage` 逻辑不变”，仅微调两处：
- **响应式双栏与收支双色标签**：桌面端采用左录入右看板圆角卡片布局，移动端（`@media`）自动切换单栏；`经营收入` 显示翠绿色标签，`经营支出` 显示暖橙红标签。
- **交互防呆**：事项摘要去除首尾空格后为空（`.trim()`）或金额小于等于 0 时拦截提交并给出轻提示；点击单条“删除”前弹出 `confirm(...)` 二次确认。

### 第三步：一键演示样本与防乱码 CSV 对账导出
继续保持既有样式与逻辑不变，新增两个实用按钮：
- **填入示例数据**：一键载入 `fixtures/sample_records.json` 中的 6 条典型经营收支演示记录（含逗号与双引号边界标题），立刻体验 `3820.00` 元总收入占 `5000` 元目标的 `76.4%` 进度条效果。
- **导出 CSV**：将当前筛选列表导出为以 UTF-8 BOM 头（`\uFEFF`）开头的 `.csv` 文件，并对含英文逗号或双引号的文本字段做标准双引号转义（`""`），确保用 Excel/WPS 打开中文不乱码、不串列。
