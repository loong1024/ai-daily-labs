## 一、场景痛点：为什么销售会议录音转写稿直接让 AI 填 CRM，销售总监根本不敢信？

B2B 销售与售前团队每天开完 45 分钟客户需求摸底会，把语音转写稿直接丢给大模型生成 CRM 商机跟进卡时，常遇到三大灾难：

1. **口水话淹没后半场（截断漏项）**：开头调设备、聊高架堵车和手冲咖啡占了大段篇幅，粗暴截断或整篇直塞导致第 30 分钟提到的“在谈竞品（帆软/ERP插件）”和第 41 分钟敲定的“周五 17:00 交报价单”全部漏抽。
2. **没提预算硬编金额 + 瞎打成交率**：客户明明说“集团财务还在切盘子、今天真给不出准数”，模型却顺嘴编出“预计预算 50 万元”，还拍脑袋打上“成交率 85%”，把销售预测搅成一锅粥。
3. **客户原话被润色篡改（死无对证）**：模型把“须与信息安全部总监赵敏联合会签”改写成“陈总一人即可拍板”，售前按错口径推进直接撞墙。

本实验带你用 **口水话去噪分块 + 低温（`temperature=0.0`）五要素抽取 + 未提项强制标 `未核实` + Python 原话子串与 `[MM:SS]` 时间戳硬核验**，确保写入 CRM 的每一条商机都句句有原话、秒秒能回听。

## 四、四步实操指引

1. **口水话去噪与全时段分块（改造 `clean_and_chunk_transcript`）**：
   - 过滤纯试音、高架堵车、倒茶与咖啡闲聊，保留全部带业务信号的 `[MM:SS] 发言人：内容`，按发言窗口分块覆盖至 `[41:10]` 结尾。
2. **低温无状态抽取商机五要素（改造 `extract_crm_deal_card`）**：
   - 固定 `temperature=0.0`、`response_json=True`，只抽 `budget`、`decision_maker`、`pain_points`、`competitors`、`next_steps`，彻底删掉 `win_probability` 主观成交率。
3. **锁死缺据 `UNVERIFIED` / `未核实` 出口**：
   - 客户未给出明确预算（如 `MTG-01`）或未看竞品（如 `MTG-02`）时，强制 `status="UNVERIFIED"`、`value="未核实"`。
4. **实现 Python 原话子串与时间戳硬核验（完善 `verify_crm_card`）**：
   - 对所有 `VERIFIED` 项，检查 `timestamp` 真实存在于 `meeting["utterances"]` 中，且 `exact_quote`（长度 ≥8 字）必须是该时间戳对应原始发言文本的**精确子串**（`quote in src_text`），否则立即抛出 `ValueError` 拦截入库！
