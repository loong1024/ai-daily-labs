## 一、二选一评审提问模板（纯中文匿名双盲防偏见版）

你将作为独立技术评审员评估两份匿名候选方案。请注意：两份方案均来自外部投稿，我本人对任一方案无偏好，请勿猜测或迎合立场，也严禁给出“各有千秋、看情况选择”的端水式结论。

## 背景与硬约束
- **业务目标**：为 30 人跨境电商客服团队上线售后工单与退换货政策智能问答助手（文档总量约 1,200 篇 Markdown 与跨页 PDF 表格，日均查询约 450 次）。
- **资源与维护约束**：仅 1 名后端工程师兼职周末维护（每周可投入工时 ≤ 4 小时）；月度总预算硬上限 1,500 元人民币；首字响应延迟 ≤ 2.5 秒；支持随时全量导出知识分块与问答日志。
- **非目标（本次不做）**：本期不做多语种实时语音通话客服，不做机房 GPU 硬件采购，不追求十万级高并发架构。

## 二、正向与互换顺序双盲对照记录（甲先乙后 vs 乙先甲后）

### 1. 四维度量化对比汇总

| 评审维度 | 托管式成熟知识库 SaaS + 标准 API 网关 | 自建开源 Kubernetes 向量集群 + 多路重排 |
| :--- | :--- | :--- |
| **实现复杂度** | **低**（2 天配置上线，免基础设施搭建） | **高**（约 3 周搭建调优，远超周末兼职带宽） |
| **故障排查难度** | **低**（仅需排查文档切片与提示词，免管底层集群） | **极高**（需单人兼职处理 K8s 节点、OOM 与分片故障） |
| **边际成本** | **约 899 元/月**（完全符合 ≤ 1,500 元预算硬红线） | **≥ 1,850 元/月**（仅裸机固定费已超预算上限 23%+） |
| **演进退出成本** | **可控但需验真**（支持一键导出 JSON/Markdown，需防元数据缺失） | **高沉没工时**（前期 3 周基建投入大，废弃时迁移清理繁琐） |

### 2. 正反两轮位置对调盲测结果
- **第 1 轮正向盲测（`<plan_alpha>` = 托管式成熟知识库 SaaS，`<plan_beta>` = 自建开源 K8s 向量集群）**：
  - 隐含假设拆解指出：`<plan_alpha>` 默认平台内置解析器能正确切分售后跨页表格；`<plan_beta>` 默认兼职工程师具备充裕排障时间且财务允许突破预算上限。
  - **推荐结论**：明确选择 **`<plan_alpha>`（托管式成熟知识库 SaaS + 标准 API 网关）**，因 `<plan_beta>` 固定机器月费 1,850 元直接击穿 1,500 元硬约束，且 K8s 运维复杂度远超每周 4 小时上限。
- **第 2 轮互换盲测（新开无记忆对话，对调顺序：`<plan_alpha>` = 自建开源 K8s 向量集群，`<plan_beta>` = 托管式成熟知识库 SaaS）**：
  - **推荐结论**：明确选择 **`<plan_beta>`（托管式成熟知识库 SaaS + 标准 API 网关）**。
- **一致性核验结论**：甲乙前后位置互换后，两轮评审的硬约束扣分点、四维优劣判断与最终胜出实体（**托管式成熟知识库 SaaS**）**100% 保持一致**，未出现位置偏见翻盘，也彻底消除了“各有千秋”端水套话。

## 三、优胜方案事前验尸（Pre-mortem）与 30 分钟最小排雷动作

### 1. 半年后最可能的死法（事前验尸）
- **托管式知识库 SaaS（当前优胜方案）头号致命死法**：
  1. **跨页表格切分失真**：跨境退换货政策 PDF 中含大量跨页合并费率表，平台默认分块器将其切碎后导致客服查询“退货运费谁承担”时频频张冠李戴，上线两个月后被客服团队彻底弃用。
  2. **隐性导出锁死或续约涨价**：半年后供应商提价，团队准备迁出时发现一键导出仅含原始文本、丢失了人工校准的问答对映射结构。
- **自建 K8s 向量集群（落选方案）死法**：月度账单持续超支被砍，且黑五大促高峰期向量库内存溢出无人及时值守，停摆两天直接宣告失败。

### 2. 推翻当前选择的反转触发信号
- **明确推翻条件**：一旦出现以下任一信号，应立即推翻“托管式知识库 SaaS”结论改选私有化/自建方案——
  1. 实测抽检 20 道真实跨页复杂表格退换货售后难题，托管 SaaS 回答准确率 **低于 80%**（即使预先转为结构化 Markdown 表格上传仍无法达标）；
  2. 公司法务新增 **“内部售后工单严禁流经第三方公有 SaaS”** 硬性合规红线，且同步将月度预算上限提升至 **≥ 3,500 元/月**、调拨专职运维工时支持。

### 3. 课后 30 分钟内可落地的最小排雷验证动作
- **今日 30 分钟排雷行动卡**：
  1. **前 10 分钟**：注册该托管式知识库 SaaS 免费试用账号，挑出团队最复杂的 **5 份跨页退换货费率 PDF 表格** 直接上传建库；
  2. **中间 15 分钟**：拿过去一周最容易扯皮的 **10 个真实售后刁钻工单问题** 实测首字响应延迟（核验是否 ≤ 2.5 秒）与跨页表格数字准确率；
  3. **最后 5 分钟**：在后台亲手点击一次 **「全量导出」** 按钮，打开导出的 JSON/Markdown 文件核验知识条目与问答日志是否完整无锁死。
